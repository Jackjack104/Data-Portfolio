## Analytics approach

1. Define the business question and metric logic before building the output.
2. Validate the source data and document important assumptions.
3. Choose methods that match the decision being made.
4. Separate observed results from unsupported explanations or causal claims.
5. Communicate the conclusion in plain language and make the next action clear.

AI-assisted work includes:

- developing and refactoring Python, SQL, and DAX

- generating test cases and checking analytical logic for edge conditions
- documenting business rules, data models, and repeatable processes
