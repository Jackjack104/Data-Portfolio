# Python Projects

These projects use Python and pandas to turn raw transaction data into defensible metrics, visual analysis, and clear business recommendations.

## Projects

- [Customer Retention & Cohort Analysis](./customer-retention-cohort-analysis/) — Identifies where customer retention declines after acquisition.
- [Website Feature Launch Performance Analysis](./website-feature-launch-performance-analysis/) — Evaluates KPI changes following a simulated feature launch without overstating causal conclusions.
- [Car Sales Performance Analysis](./car-sales-performance-analysis/) — Separates regional, manufacturer, model, transaction-volume, and pricing performance.
